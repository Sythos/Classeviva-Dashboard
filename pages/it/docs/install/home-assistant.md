# Installa Home Assistant

Home Assistant esegue l'integrazione CVV Dashboard. Installa e configura Home Assistant prima di installare HACS o CVV Dashboard.

## Scegli il tipo di installazione

Home Assistant supporta diversi tipi di installazione. I passaggi dipendono dal dispositivo e dal sistema operativo.

1. Apri la [guida ufficiale all'installazione di Home Assistant](https://www.home-assistant.io/installation/).
2. Seleziona il tipo di installazione adatto al tuo dispositivo.
3. Segui tutta la guida per quel tipo.
4. Apri Home Assistant nel browser e completa la configurazione iniziale.
5. Crea un backup prima di aggiungere integrazioni personalizzate.

## Verifica l'installazione

Prima di continuare:

- Home Assistant deve aprirsi nel browser.
- Il tuo utente deve avere i diritti di amministratore.
- Home Assistant deve avere la versione 2024.7.0 o successiva.
- Devi sapere dove trovare **Impostazioni > Dispositivi e servizi**.

Se Home Assistant non è pronto, consulta le [pagine ufficiali di assistenza](https://www.home-assistant.io/help/).
