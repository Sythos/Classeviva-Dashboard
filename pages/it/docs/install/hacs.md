# Installa HACS

HACS installa CVV Dashboard e altri elementi della community in Home Assistant.

## Prima di iniziare

- Home Assistant deve essere installato e pronto.
- Usa un account Home Assistant con i diritti di amministratore.
- Leggi i [requisiti ufficiali di HACS](https://www.hacs.dev/docs/use/download/prerequisites/).

## Installa e configura HACS

I passaggi di installazione di HACS possono cambiare. Segui la [guida ufficiale aggiornata per scaricare HACS](https://www.hacs.dev/docs/use/download/download/). Scegli i passaggi per il tuo tipo di installazione di Home Assistant.

Al termine della guida:

1. Riavvia Home Assistant se la guida lo richiede.
2. Apri **Impostazioni > Dispositivi e servizi**.
3. Seleziona **Aggiungi integrazione**.
4. Cerca **HACS** e selezionalo.
5. Segui la schermata di configurazione. Completa il passaggio GitHub quando appare.
6. Verifica che **HACS** compaia nel menu laterale di Home Assistant.

Per altra assistenza, usa la [documentazione ufficiale HACS](https://www.hacs.dev/docs/).
