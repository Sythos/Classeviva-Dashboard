# Install HACS

HACS installs CVV Dashboard and other community items in Home Assistant.

## Before you start

- Home Assistant must be installed and ready.
- Use a Home Assistant administrator account.
- Read the official [HACS requirements](https://www.hacs.dev/docs/use/download/prerequisites/).

## Install and set up HACS

HACS installation steps can change. Use the current [official HACS download guide](https://www.hacs.dev/docs/use/download/download/). Select the steps for your Home Assistant install type.

When the guide is complete:

1. Restart Home Assistant if the guide asks you to do this.
2. Open **Settings > Devices & services**.
3. Select **Add integration**.
4. Search for **HACS** and select it.
5. Follow the setup screen. Complete the GitHub step when it appears.
6. Confirm that **HACS** appears in the Home Assistant sidebar.

For more help, use the [official HACS documentation](https://www.hacs.dev/docs/).

## Continue

Install [CVV Dashboard from HACS](cvv-dashboard.md). You need the repository address and the **Integration** category.
