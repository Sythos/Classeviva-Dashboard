# Install Home Assistant

Home Assistant runs the CVV Dashboard integration. Install and set up Home Assistant before you install HACS or CVV Dashboard.

## Choose an install type

Home Assistant supports several install types. The steps depend on your hardware and operating system.

1. Open the official [Home Assistant installation guide](https://www.home-assistant.io/installation/).
2. Select the install type for your device.
3. Follow the full guide for that type.
4. Open Home Assistant in a browser and complete the first setup.
5. Create a backup before you add custom integrations.

## Check the installation

Before you continue:

- Home Assistant must open in a browser.
- Your user must have administrator access.
- Home Assistant must run version 2024.7.0 or later.
- You must know where to find **Settings > Devices & services**.

If Home Assistant is not ready, use the official [Home Assistant help pages](https://www.home-assistant.io/help/).

## Continue

Install [HACS](hacs.md) next. HACS installs CVV Dashboard and manages its updates.
