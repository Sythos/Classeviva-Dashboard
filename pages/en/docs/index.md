# CVV Dashboard

CVV Dashboard brings ClasseViva data into Home Assistant. It adds a Lovelace card, a student panel, sensors, calendars, and actions.

The integration reads the data for the account that you set up. Home Assistant stores the user name and password. The access token stays in memory and is renewed when needed.

## Start here

1. [Install Home Assistant](install/home-assistant.md).
2. [Install HACS](install/hacs.md).
3. [Install and set up CVV Dashboard](install/cvv-dashboard.md).
4. [Add the card to a Lovelace dashboard](install/lovelace.md).
5. Read the guide for [one student](guide/single-student.md) or [two or more students](guide/multiple-students.md).

## What you can view

- General averages and term results.
- Grades, subjects, and recent marks.
- School notices and their attachments.
- Events, homework, teacher notes, and room bookings.
- Teacher comments, disciplinary notes, and published report cards.
- Home Assistant calendars for each student.

The [Views and symbols](guide/features.md) page lists every card view, symbol, and control.

## Requirements

- Home Assistant 2024.7.0 or later.
- HACS installed in Home Assistant.
- A valid ClasseViva parent or student account.
